## 比喻說明

```
🖼️ 相框比喻：

   AppLayout = 相框（永遠不變）
   Sidebar   = 相框左邊的裝飾（永遠不變）
   Outlet    = 可以替換的照片（根據網址切換）

🏢 大樓比喻：

   AppLayout = 大樓外殼 + 電梯間
   Sidebar   = 電梯按鈕面板（每層樓都看得到）
   Outlet    = 各樓層的房間（搭電梯到不同樓層看到不同內容）
```

## 7. 數量勾稽邏輯

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            數量勾稽 (Reconciliation)                         │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────┐         ┌─────────────┐         ┌─────────────┐
    │   進料數量   │    =    │   OK 數量   │    +    │   NG 數量   │
    │ incomingQty │         │    okQty    │         │    ngQty    │
    └─────────────┘         └─────────────┘         └─────────────┘
          │                                               │
          │                                               │
          ▼                                               ▼
    ┌─────────────────────────────────────────────────────────────┐
    │                        差異數計算                            │
    │        difference = incomingQty - (okQty + ngQty)           │
    └─────────────────────────────────────────────────────────────┘
                                  │
                    ┌─────────────┴─────────────┐
                    │                           │
                    ▼                           ▼
           ┌─────────────────┐        ┌─────────────────┐
           │  difference = 0 │        │ difference ≠ 0  │
           │    ✅ 平衡      │        │   ❌ 不平衡     │
           │   (綠色邊框)    │        │   (紅色邊框)    │
           └─────────────────┘        └─────────────────┘

    ┌─────────────────────────────────────────────────────────────┐
    │                        良率計算                              │
    │           yieldRate = (okQty / totalProcessed) × 100%       │
    └─────────────────────────────────────────────────────────────┘
```
